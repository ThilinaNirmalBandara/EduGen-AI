# Local vector assets

The six SVGs in `svg/` were authored for EduGen-AI. They contain only vector paths,
circles and presentation attributes: no scripts, external images, fonts or network
references. Both experimental renderers resolve the same asset IDs through the
checked-in catalog. Their artistic colors are intentional; themes control the
canvas, foreground, captions and highlights without modifying cached lessons.

These assets may be used and modified under the project's license. If no project
license has been selected, the SVG assets themselves are dedicated under CC0-1.0.
